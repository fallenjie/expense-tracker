# PRD-001 记账app

## 背景
用户需要一个可多端同步的 H5 记账应用，支持日常账单记录、分类管理、收支统计及日报/月报，并可设置月度预算上限。

## 原始需求来源
- **inbox 文件**: expense-tracker/00_inbox/2026-04-29-记账app需求.md
- **用户原始描述**:
  1. 支持用户自行输入账单
  2. 支持账单分类
  3. 支持日报和月报
  4. 载体：H5 App
  5. 数据需支持多端同步
  6. 账单需记录收入和支出
  7. 支持设置每月预算上限
  8. 技术栈：H5 + MySQL（BaaS：Appwrite）
  9. 采用精简方案

- 用户可新增/编辑/删除自定义分类

### FUNC-02 分类管理
- 用户可新增自定义分类（支出/收入）
- 用户可编辑自定义分类名称
- 用户可删除自定义分类
- 预设分类系统自动初始化，新用户注册后即生效

### FUNC-03 日报
- 统计**当日（自然日 0–24点）**所有账单
- 显示：收入总计、支出总计、结余
- 支出按分类汇总（饼图或列表）
- 收支记录列表（按时间倒序）

### FUNC-04 月报
- 统计**自然月**所有账单
- 显示：收入总计、支出总计、结余
- 支出按分类汇总
- 月度预算消耗进度（如已设置）
- 收支记录列表

### FUNC-05 多端同步
- 实时同步：每次操作即时同步到服务端
- 冲突策略：服务端时间戳优先（Last Write Wins）
- 支持 H5 网页访问；未来扩展 iOS/Android
- 依赖 Appwrite Database

### FUNC-06 月度预算
- 用户自行设置每月预算上限（无默认值）
- 达预算80%：弹窗提醒
- 达预算100%：再次弹窗提醒
- 提醒后用户可继续录入（不阻止）

### FUNC-07 H5 App 载体
- 移动端浏览器即可访问
- 响应式布局，适配手机屏幕

## 技术需求

### TECH-01 技术栈
- **前端**：H5（移动端适配）
- **后端**：Appwrite（BaaS）
  - Database：存储账户、账单、分类、预算数据
  - Auth：用户注册/登录（手机号+微信）
  - Functions：预算提醒定时任务、数据统计计算

### TECH-02 MVP 一期范围

| 优先级 | 功能 |
|--------|------|
| P0 | 登录、账户管理、账单录入、分类管理 |
| P1 | 日报、月报、账单搜索 |
| P2 | 预算提醒（80%/100%弹窗） |

> 完整预算报告（P2完整）排入二期

## 用户故事

| 角色 | 场景 | 期望 |
|------|------|------|
| 用户 | 日常消费后 | 打开 H5 App，快速录入一条支出账单 |
| 用户 | 月底回顾 | 查看月报，了解本月收支结构和预算消耗情况 |
| 用户 | 控制消费 | 设置月度预算，超预算时获得提醒 |
| 用户 | 多设备使用 | 在手机和电脑上查看同一份账单，数据一致 |

## 验收标准

1. ✅ 用户可在 H5 App 中**手动录入**一条账单（金额 + 类型 + 分类 + 日期），数据保存成功
2. ✅ 账单可按**分类**筛选查看
3. ✅ **日报**显示当日（自然日）所有账单及收支汇总；**月报**显示当月所有账单及收支汇总
4. ✅ 多端登录同一账号，数据**实时同步**（服务端时间戳优先）
5. ✅ 用户可设置**月度预算上限**
6. ✅ 超过月度预算80%/100%时**各弹窗提醒一次**，但可继续录入
7. ✅ 收支统计准确，无计算错误
8. ✅ 新用户注册后自动初始化24个预设分类
9. ✅ 用户可新增/编辑/删除自定义分类
